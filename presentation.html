Problem Statement

What Problem Are We Solving?

📋

Manual Ordering

Retailers place orders via phone calls and handwritten slips — no digital record, no confirmation trail

📦

Stock Mismatches

No real-time inventory visibility leads to over-selling, stock disputes, and delayed fulfillment

🧾

Manual Invoicing

GST invoices are handwritten and error-prone — no automated calculation of CGST/SGST or promotional discounts

Problem Statement: Currently, retail pharmacies face inefficient, manual order placement when purchasing medicines from The Jangareddygudem Medical Agencies, resulting in inventory mismatches, delayed order confirmation, and no real-time stock visibility. This project aims to build a secure, real-time web portal so that both the agency owner and retailers can manage orders, track inventory, and generate GST-compliant invoices digitally.
Problem Statement

Who Is Affected & Why It Matters

👤 Stakeholders Affected

  • Agency Owner — No dashboard for real-time order visibility or stock control
  • Retail Pharmacies — Cannot browse stock or check availability without calling
  • Accountant/Billing Team — Manual GST invoice generation wastes hours daily
  • Both Parties — No payment ledger or outstanding credit tracking

⚡ Impact of Not Solving It

  • Inventory over-commitment when two retailers buy the same stock simultaneously
  • Delayed payments due to lack of digital credit ledger
  • GST compliance risk from handwritten, error-prone invoices
  • Business cannot scale — owner bottleneck for every transaction

✅ High-Level Approach

Build a dual-role web application — an Owner Dashboard for inventory & order management, and a Retailer Storefront for browsing, ordering, and tracking — with real-time database sync, secure authentication, and automated invoice generation.

Objectives

Project Objectives

  • 01
    Design & Develop a dual-role web portal with secure Supabase Auth login for both the Agency Owner and Retailer pharmacies — with role-based route protection.
  • 02
    Implement real-time inventory management with stock deduction on checkout — using PostgreSQL RPC transactions to eliminate race conditions.
  • 03
    Develop a promotional scheme engine that parses and applies "Buy X Get Y Free" dispatch formulas (e.g., 10+2) accurately on every order line item.
  • 04
    Build a GST-compliant printable invoice system with dynamic CGST/SGST computation, brand details, batch number, expiry date, and WhatsApp sharing.
  • 05
    Deploy the production-ready application on Vercel with Row-Level Security (RLS) policies on all Supabase tables to ensure data privacy and integrity.
